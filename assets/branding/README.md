# dar-backup Branding

This directory contains the official branding assets for the [`dar-backup`](https://github.com/per2jensen/dar-backup) project.

## Included assets

| File | Intended use |
|---|---|
| `dar-backup-64x64.png` | Small icons, avatars, and compact UI elements |
| `dar-backup-128x128.png` | Docker Hub, GitHub, and similar project listings |
| `dar-backup-256x256.png` | General documentation and higher-resolution use |

All PNG files use transparent outer corners so that the rounded icon renders cleanly on both light and dark backgrounds.

## Design

The icon represents the main ideas behind dar-backup:

- **FULL / DIFF / INCR** — supported backup generations
- **Shield and check mark** — verification and integrity
- **Restore arrow** — recoverability and restoration

The dark navy and restrained blue palette is intended to convey reliability, data protection, and infrastructure software rather than affiliation with any third-party product or project.

The artwork deliberately does not incorporate third-party logos or trademarks.

## Modifications

When resizing the icon, use one of the supplied sizes where possible rather than repeatedly rescaling an already reduced version.

Avoid altering:

- aspect ratio
- colors
- shield or restore-arrow geometry
- typography
- relative placement of the visual elements
